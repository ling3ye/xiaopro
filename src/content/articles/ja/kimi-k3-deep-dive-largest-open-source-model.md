## 一、はじめに：オープンソースモデルが初めて「天井」に手が届いた

2026 年 7 月 16 日、上海世界人工知能大会（WAIC）開幕の前日、Moonshot AI が衝撃の一発を投げ込んだ——**Kimi K3** です。

その肩書きは大げさに聞こえますが、すべて事実です。

- **総パラメータ 2.8 兆**で、現在世界最大パラメータ規模のオープンソースモデルであり、DeepSeek V4 Pro（1.6 兆）や Zhipu GLM-5 シリーズ（7440 億）を大きく上回ります。
- **世界初の 3 兆パラメータ級オープンソースモデル**。
- **オープンソースモデル史上初めて、主要ランキングでクローズドのフラッグシップを正面から上回った**——フロントエンドプログラミングのブラインドテストランキング Frontend Code Arena で、Kimi K3 は 1679 ポイントで首位に立ち、Anthropic の Claude Fable 5 と OpenAI の GPT-5.6 Sol を抑えました。

新華社の言葉を借りれば、これは「我が国の人工知能モデルの発展が新たな一歩を踏み出したことを示す」ものです。一方、一般ユーザーにとってより現実的な問いは「どこが強いのか」「自分にどう関係するのか」「どこで使えるのか」です。本記事で一度に整理します。

## 二、Kimi K3 とは何か？

### 2.1 基本プロフィール

| 項目 | 内容 |
|---|---|
| 開発元 | Moonshot AI（2023 年に清華系出身の起業家 Yang Zhilin が創業、Alibaba と Tencent が出資） |
| 公開時期 | 2026 年 7 月 16 日に発表、7 月 27 日に完全な重みをオープンソース化 |
| アーキテクチャ | MoE（混合専門家）モデル。93 層、計 896 個のエキスパートで、各 token でそのうち 16 個だけを活性化 |
| 総パラメータ / 活性化パラメータ | 2.8 兆 / 約百億級（スパース活性化のため、推論コストは規模から想像されるよりはるかに低い） |
| コンテキストウィンドウ | 100 万 token（1,048,576）。一括料金で段階分けなし |
| モダリティ | テキスト＋画像理解をネイティブサポート（MoonViT-V2 ビジョンエンコーダ）。一部チャネルでは動画入力にも対応済み |
| オープンソースライセンス | 独自の Kimi K3 License（MIT 類似、収入に応じた段階的条項付き） |

### 2.2 二つのコア技術イノベーション

Kimi K3 の見どころは「大きさ」だけでなく、情報の処理方法にあります。

**1. KDA 混合線形アテンション（Kimi Delta Attention）**

従来の Transformer の全アテンション機構で長文を処理する場合、計算量はテキスト長に対してほぼ二乗オーダーで増加します——内容が 1 倍になると計算量は約 4 倍になります。これが超長文の実用化が難しい根本原因です。K3 は 93 層のうち 69 層で自社開発の KDA 線形アテンションモジュールを採用し、計算量をほぼ**線形増加**まで抑えています。その結果、KV キャッシュは約 75% 削減、百万 token のデコードスループットは約 6.3 倍に向上しました。端的に言えば、同じ計算力でより長く「読み」、より深く考えられるということです。

**2. アテンション残差（Attention Residuals / AttnRes）**

モデルが大きく層が増えるほど、層間の情報伝達は減衰・歪みやすくなり、学習が崩壊しやすくなります。アテンション残差技術は、モデルが深さをまたいで表現を選択的に検索できるようにするもので、機械的に層ごとに足し上げるのではありません——2.8 兆パラメータの巨大モデルに「スタビライザー」を搭載したようなものです。公式によれば、二つの技術の組み合わせにより、K3 は K2 と比べて約 **2.5 倍の学習スケーリング効率**向上を実現しています。

### 2.3 オープンソース戦略：誰でもダウンロードできるが、大手は「届け出」が必要

7 月 27 日、K3 の完全な重みと技術レポートが Hugging Face と GitHub に公開されました。ライセンスは全体として MIT に近く、誰でも無料で使用・改変・配布・ファインチューニングできます。収入に関わる制限は以下の 2 点だけです。

- 「モデル・アズ・ア・サービス」方式で K3 推論を大規模に再販するクラウド事業者は、連続 12 か月の収入が 20 万ドルを超えた時点で Moonshot と個別契約が必要。
- 月間アクティブユーザー 1 億超、または月収 200 万ドル超の商用プロダクトは、インターフェースに「Kimi K3」を明示する必要があります。

大多数の開発者や中小企業にとって、これは実質「無料で商用利用可能」です。

### 3.4 コストパフォーマンス：安さは相対的なもの

国内の公式価格は入力 ¥20/百万 token、出力 ¥100/百万 token、キャッシュヒット ¥2/百万 token です。

K3 の価格は Claude Fable 5 の約 1/3 ですが、自社の K2.6 より 4〜5 倍高くなっています。節約のカギは**キャッシュ**です。プログラミングのシーンでは、公式によるとキャッシュヒット率は 90% を超え、ヒットした部分の入力価格は 1 割になります。OpenRouter での実測では実効入力コストは約 $0.55/百万 token です。第三者の試算では、同じ一連の agent コーディングタスク（入力 10 万＋出力 2 万）で K3 は約 $0.60、Fable 5 は約 $2.00 になります。

## 四、どこで Kimi K3 を使えるか？

皆さんが最も関心を持つ部分であり、私が最近ずっと探していたことでもあります。ここに記録して共有します。ハードルの低い順に並べています。

### 4.1 WorkBuddy（最も手軽な方法の一つ）

[https://www.workbuddy.cn/](https://www.workbuddy.cn/events/invite?inviteCode=421qev5h73caj0) （WorkBuddy 招待リンク）

なぜ Kimi 公式サイトを第一に推さないのか？それは現状まったく開放されておらず、いつサブスクリプションが開放されるかわからないからです。もう 2 週間ほど待っています。Kimi の既存会員なら、この部分は読み飛ばして構いません（笑）。

**WorkBuddy は Kimi K3 を標準で統合しています**——いま読んでいるこの対話も、裏側では Kimi K3 が動いています。API キーの格闘やパラメータの調査をしたくない一般ユーザーやオフィスシーンなら、WorkBuddy を開いてそのまま使えます。文書作成、表作成、PDF の読み取り、コード実行、Web ページ生成まで、K3 の長いコンテキストと Agent 能力が WorkBuddy では開封即利用の状態です。これは国内ユーザーが K3 のフル能力をゼロハードルで体験できる最短経路の一つです。

### 4.2 Kimi 公式プロダクトラインナップ

https://kimi.com

- **Kimi Web 版 / App**（kimi.com / kimi.moonshot.cn）：登録すればすぐ対話できます。無料枠にはコンテキストと頻度の制限があり、会員は完全な 1M コンテキストを解放できます。
- **Kimi Work**：デスクトップのナレッジワーク環境（Windows / Apple シリコン搭載 Mac、3.1.0 バージョン以降）。
- **Kimi Code**：ターミナル向けプログラミング Agent。`npm i @moonshot-ai/kimi-code` でインストールし、`/model` で K3 に切り替えます。

### 4.3 公式 API（開発者向け）

- プラットフォーム：platform.moonshot.cn（国内）/ platform.kimi.ai（国際）。
- OpenAI SDK と完全互換。モデル ID は `kimi-k3` で、`base_url` を `https://api.moonshot.ai/v1` に向けるだけで既存コードを移行できます。

```python
from openai import OpenAI

client = OpenAI(
    api_key="あなたの API キー",
    base_url="https://api.moonshot.ai/v1"
)
resp = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "このコードを分析して"}]
)
```

### 4.4 サードパーティプラットフォーム

- **OpenRouter**：モデル ID `moonshotai/kimi-k3`。公式と同じ価格で上乗せなし。
- **SiliconFlow**：国内からのアクセスに優しい。
- **Cloudflare Workers AI、Groq**：こちらでも提供済み。
- **セルフホスティング**：Hugging Face / GitHub から重みをダウンロードでき、vLLM / SGLang に対応。MXFP4/NVFP4 量子化にも対応——ただし本番レベルのデプロイには 64 枚以上のカードを備えるスーパーノードが必要で、一般の方は眺める程度でよいでしょう。

### 4.5 ちょっとした注意点

K3 のリリース後、需要の殺到により Kimi 公式会員の新規購入は一時停止されました（7 月 20 日から既存ユーザーを優先）。公式チャネルが混雑している場合は、WorkBuddy、OpenRouter、SiliconFlow などが信頼できる代替入口です。

## 五、最後に

Kimi K3 の意義は、数年後にならないと完全には見えてこないかもしれません。

1. **オープンソースがクローズドに追いつけることを証明しました。** 2.8 兆パラメータ、Arena プログラミングランキング 1 位、知能指数のオープンソース 1 位——「オープンソース＝二流」の時代は終わりました。
2. **中国のチームが基盤アーキテクチャのイノベーションを成し遂げられることを証明しました。** KDA 線形アテンションとアテンション残差は単なるエンジニアリングの積み上げではなく、「超長文を安く計算し、超巨大モデルを安定して学習させる」という二つの世界級の難題への独創的な解法です。
3. **最先端能力の価格を引き下げました。** Claude の 3 分の 1 の価格、誰でもダウンロードできる重みにより、より多くのプロダクトや研究が K3 の肩の上に生まれていくでしょう。

もちろん冷静さも必要です。総合体験では最強のクローズドモデル 2〜3 つにまだ遅れをとっており、推論速度は速くなく、思考モードでの token 消費も激しいです。万能の鍵ではありません。しかし、**長文ドキュメント、リポジトリ全体のコード、深掘り調査、フロントエンド開発**といった骨の折れるタスクに直面しているなら、Kimi K3 は現在オープンソースの世界が提供できる最強の答えです——しかも、いま WorkBuddy を開けばすぐ使えます。
