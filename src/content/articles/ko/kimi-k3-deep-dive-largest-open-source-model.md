## 1. 들어가며: 오픈소스 모델이 처음으로 "천장"을 만지다

2026년 7월 16일, 상하이 세계인공지능대회(WAIC) 개막 하루 전, Moonshot AI가 엄청난 폭탄을 던졌습니다. 바로 **Kimi K3**입니다.

그 수식어가 거창해 보이지만 전부 사실입니다:

- **총 파라미터 2.8조** — 현재 전 세계에서 가장 큰 파라미터 규모의 오픈소스 모델로, DeepSeek V4 Pro(1.6조)와 Zhipu GLM-5 시리즈(7,440억)를 크게 앞섭니다.
- **전 세계 최초의 3조 파라미터급 오픈소스 모델**입니다.
- **오픈소스 모델 역사상 처음으로 메이저 순위표에서 폐쇄형 플래그십을 정면으로 추월**했습니다. 프런트엔드 코딩 블라인드 테스트인 Frontend Code Arena에서 Kimi K3가 1679점으로 1위에 오르며 Anthropic의 Claude Fable 5와 OpenAI의 GPT-5.6 Sol을 눌렀습니다.

신화통신의 표현을 빌리면, 이는 "중국 인공지능 모델 발전이 한 걸음 더 나아갔음을 의미"합니다. 일반 사용자에게 더 실용적인 질문은 이것입니다. 어디가 강한가? 나와 무슨 관계가 있나? 어디서 쓸 수 있나? 이 글에서 한 번에 정리해 드리겠습니다.

## 2. Kimi K3란 무엇인가?

### 2.1 기본 정보

| 항목 | 내용 |
|---|---|
| 개발사 | Moonshot AI (2023년 칭화대 출신 창업자 양즈린이 설립, 알리바바·텐센트 모두 투자사) |
| 출시 시점 | 2026년 7월 16일 공개, 7월 27일 전체 가중치 오픈소스 공개 |
| 아키텍처 | MoE 혼합 전문가 모델, 93개 레이어, 총 896개 전문가, 각 token마다 16개만 활성화 |
| 총 파라미터 / 활성 파라미터 | 2.8조 / 약 100억 수준 (희소 활성화, 추론 비용은 규모가 주는 인상보다 훨씬 낮음) |
| 컨텍스트 윈도우 | 100만 token (1,048,576), 일괄 제공으로 등급 구분 없음 |
| 모달리티 | 텍스트 + 이미지 이해 네이티브 지원 (MoonViT-V2 비전 인코더), 일부 채널은 비디오 입력 지원 |
| 오픈소스 라이선스 | 자체 Kimi K3 License (MIT 유사, 수익 등급 조항 포함) |

### 2.2 두 가지 핵심 기술 혁신

Kimi K3의 볼거리는 단순히 "크다"는 것만이 아니라 정보를 처리하는 방식에 있습니다:

**1. KDA 하이브리드 선형 어텐션 (Kimi Delta Attention)**

기존 Transformer의 풀 어텐션 메커니즘은 긴 텍스트를 처리할 때 연산량이 텍스트 길이에 따라 거의 제곱 수준으로 늘어납니다. 내용이 2배가 되면 연산량은 약 4배가 됩니다. 이것이 초장문 텍스트가 현실에서 쓰이기 어려웠던 근본 원인입니다. K3는 93개 레이어 중 69개 레이어에 자체 개발한 KDA 선형 어텐션 모듈을 사용해 연산량을 거의 **선형 증가** 수준까지 낮췄습니다. 그 결과 KV 캐시는 약 75% 줄고, 백만 token 디코딩 처리량은 약 6.3배 향상됐습니다. 쉽게 말해, 같은 연산 능력으로 더 길게 "읽고" 더 깊게 생각할 수 있다는 뜻입니다.

**2. 어텐션 잔차 (Attention Residuals / AttnRes)**

모델이 클수록, 레이어가 많을수록 정보가 레이어 사이를 오가며 감쇠·왜곡되기 쉽고 학습이 무너지기 쉽습니다. 어텐션 잔차 기술은 모델이 깊이에 걸쳐 표현을 선택적으로 검색하게 해서, 기계적으로 레이어를 쌓아 더하는 대신 2.8조 파라미터의 거대 모델에 일종의 "안정 장치"를 달아준 셈입니다. 공식 발표에 따르면, 두 기술을 합치면 K3는 K2 대비 약 **2.5배의 학습 확장 효율** 향상을 얻었습니다.

### 2.3 오픈소스 전략: 누구나 내려받을 수 있지만, 대기업은 "신고"해야

7월 27일, K3의 전체 가중치와 기술 보고서가 Hugging Face와 GitHub에 올라왔습니다. 라이선스는 MIT에 가깝습니다. 누구나 무료로 사용·수정·배포·파인튜닝할 수 있습니다. 다만 수익 관련 제한이 두 가지 있습니다:

- "모델 서비스" 방식으로 K3 추론을 대규모 재판매하는 클라우드 업체는 12개월 연속 수익이 20만 달러를 넘으면 Moonshot과 별도로 계약해야 합니다.
- 월간 활성 사용자 1억 명 이상 또는 월 수익 200만 달러 이상인 상업 제품은 인터페이스에 "Kimi K3"를 눈에 띄게 표시해야 합니다.

대다수 개발자와 중소기업에게는 사실상 "무료 상업 사용 가능"이나 다름없습니다.

## 3. 정면 승부: 각종 순위표에서의 실제 위치

벤치마크 점수는 나눠서 봐야 합니다. 하나는 **서드파티 기관의 독립 재측정**(신뢰도 높음)이고, 하나는 **업체 자체 발표**(참고용)입니다. 먼저 가장 신뢰할 만한 종합 순위 두 개부터 보겠습니다.

- ✅ **심층 조사와 오피스 자동화**: BrowseComp에서 신기록을 세웠습니다.

- ⚠️ **종합 체감**: 공식 측도 인정하듯, 상호작용 디테일과 작업 완성도의 "체감"에서는 여전히 Claude Fable 5와 GPT-5.6 Sol에 약간 밀립니다. 서드파티 실측 출력 속도는 약 36~55 token/s로 빠른 편은 아니며, 사고 모드에서 token 소모가 다소 많습니다.

K3의 가격은 Claude Fable 5의 약 1/3이지만, 자사의 K2.6보다는 4~5배 비쌉니다. 핵심 절약 팁은 **캐시**입니다. 코딩 시나리오에서 공식 측은 캐시 히트율이 90%를 넘을 수 있다고 하며, 히트 구간 입력 가격이 10분의 1로 떨어지므로 OpenRouter 실측 기준 유효 입력 비용은 약 $0.55/백만 token입니다. 서드파티 계산에 따르면, 같은 한 라운드의 agent 코딩 작업(입력 10만 + 출력 2만)에서 K3는 약 $0.60, Fable 5는 약 $2.00가 듭니다.

## 4. Kimi K3를 어디서 쓸 수 있을까?

가장 궁금해하시는 부분이자 제가 최근 계속 찾아본 부분이라, 여기에 정리해 공유합니다. 진입 문턱이 낮은 순서로 나열했습니다:

### 4.1 WorkBuddy (가장 손쉬운 방법 중 하나)

[https://www.workbuddy.cn/](https://www.workbuddy.cn/events/invite?inviteCode=421qev5h73caj0) (WorkBuddy 초대 링크)

왜 Kimi 공식 홈페이지를 첫 번째로 추천하지 않을까요? 지금은 아예 구독이 열려 있지 않아서 언제 열릴지 알 수 없습니다. 저도 벌써 2주째 기다리고 있어요. Kimi 기존 회원이시라면 바로 건너뛰셔도 됩니다. ㅎㅎ.

**WorkBuddy는 이미 Kimi K3를 내장해 연결했습니다.** 지금 읽고 계신 이 대화도 그 뒤에서 Kimi K3가 돌아가고 있습니다. API key를 만지작거리거나 파라미터를 연구하고 싶지 않은 일반 사용자와 오피스 환경이라면 WorkBuddy를 열어 바로 쓰면 됩니다. 문서 작성, 표 만들기, PDF 읽기, 코드 실행, 웹 페이지 생성까지, K3의 긴 컨텍스트와 Agent 능력이 WorkBuddy에서 바로 쓸 수 있는 상태로 제공됩니다. 이는 국내 사용자가 문턱 없이 K3의 완전한 능력을 체험하는 가장 짧은 경로 중 하나이기도 합니다.

### 4.2 Kimi 공식 제품 라인업

https://kimi.com

- **Kimi 웹 버전 / 앱** (kimi.com / kimi.moonshot.cn): 가입만 하면 대화 가능하며, 무료 할당량에는 컨텍스트와 사용 빈도 제한이 있습니다. 멤버십을 구독하면 전체 1M 컨텍스트가 해제됩니다.
- **Kimi Work**: 데스크톱 지식 작업 환경 (Windows / Apple 실리콘 Mac, 3.1.0 버전부터).
- **Kimi Code**: 터미널 코딩 Agent로, `npm i @moonshot-ai/kimi-code`로 설치하고 `/model`로 K3로 전환합니다.

### 4.3 공식 API (개발자)

- 플랫폼: platform.moonshot.cn (국내) / platform.kimi.ai (해외).
- OpenAI SDK와 완전히 호환되며, 모델 ID는 `kimi-k3`입니다. `base_url`을 `https://api.moonshot.ai/v1`로 지정하면 기존 코드를 그대로 마이그레이션할 수 있습니다.

```python
from openai import OpenAI

client = OpenAI(
    api_key="당신의 API 키",
    base_url="https://api.moonshot.ai/v1"
)
resp = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "이 코드를 분석해 줘"}]
)
```

### 4.4 서드파티 플랫폼

- **OpenRouter**: 모델 ID `moonshotai/kimi-k3`, 공식과 동일한 가격으로 추가 비용 없음.
- **SiliconFlow (실리콘플로우)**: 국내 접속이 편리합니다.
- **Cloudflare Workers AI, Groq**: 이미 등록되어 있습니다.
- **자체 배포**: Hugging Face / GitHub에서 가중치를 내려받고 vLLM / SGLang, MXFP4/NVFP4 양자화를 지원합니다. 다만 프로덕션급 배포에는 64장 이상의 슈퍼노드가 필요하므로 일반인은 참고만 하시면 됩니다.

### 4.5 작은 주의사항

K3 공개 후 수요가 폭발해 Kimi 공식 멤버십은 한때 신규 구매가 잠시 중단됐습니다(7월 20일부터 기존 사용자 보호 우선). 공식 채널이 혼잡하다면 WorkBuddy, OpenRouter, SiliconFlow 등이 모두 믿을 만한 대체 진입로입니다.

## 5. 마치며

Kimi K3의 의미는 몇 년이 지나야 온전히 보일지도 모릅니다:

1. **오픈소스가 폐쇄형을 따라잡을 수 있음을 증명했습니다.** 2.8조 파라미터, Arena 코딩 부문 1위, 지능 지수 오픈소스 1위 — "오픈소스 = 2류" 시대가 끝났습니다.
2. **중국 팀이 근본적인 아키텍처 혁신을 해낼 수 있음을 증명했습니다.** KDA 선형 어텐션과 어텐션 잔차는 단순한 엔지니어링 물량 투입이 아니라, "초장문 텍스트를 저비용으로 연산하고, 초대형 모델을 안정적으로 학습하는" 두 세계적 난제에 대한 독창적 해법입니다.
3. **최전선 능력의 가격을 끌어내렸습니다.** Claude의 3분의 1 가격, 누구나 내려받을 수 있는 가중치는 더 많은 제품과 연구가 K3의 어깨 위에서 성장하도록 할 것입니다.

물론 냉정함도 유지해야 합니다. 종합 체감에서는 여전히 가장 강한 두세 개의 폐쇄형 모델에 뒤처지고, 추론 속도가 빠르지 않으며, 사고 모드의 token 소모도 큽니다. 만능 열쇠는 아닙니다. 하지만 **장문 문서, 저장소 전체 코드, 심층 조사, 프런트엔드 개발** 같은 까다로운 과제를 마주하고 있다면, Kimi K3는 지금 오픈소스 세계가 줄 수 있는 가장 강력한 답입니다. 그리고 지금 WorkBuddy를 열면 바로 쓸 수 있습니다.
