## 一、引言：開源模型第一次摸到了「天花板」

2026 年 7 月 16 日，就在上海世界人工智慧大會（WAIC）開幕前一天，月之暗面（Moonshot AI）扔出了一顆重磅炸彈——**Kimi K3**。

它的頭銜很唬人，但都是事實：

- **總參數 2.8 兆**，是目前全球參數規模最大的開源模型，遠超 DeepSeek V4 Pro（1.6 兆）和智譜 GLM-5 系列（7440 億）；
- **全球首個 3 兆參數級別的開源模型**；
- **開源模型歷史上第一次在主流排行榜上正面超越閉源旗艦**——在前端程式設計盲測榜 Frontend Code Arena 上，Kimi K3 以 1679 分登頂，壓過 Anthropic 的 Claude Fable 5 和 OpenAI 的 GPT-5.6 Sol。

用新華社的話說，這「標誌著我國人工智慧模型發展邁出新的一步」。而對普通使用者來說，更實際的問題是：它強在哪？跟我有什麼關係？去哪能用上？這篇文章一次講清楚。

## 二、Kimi K3 是什麼？

### 2.1 基本檔案

| 項目 | 參數 |
|---|---|
| 開發方 | 月之暗面（Moonshot AI，2023 年由清華系創業者楊植麟創立，阿里、騰訊均為投資方） |
| 發布時間 | 2026 年 7 月 16 日發布，7 月 27 日開源完整權重 |
| 架構 | MoE 混合專家模型，93 層，共 896 個專家，每個 token 僅啟動其中 16 個 |
| 總參數 / 啟動參數 | 2.8 兆 / 約百億級（稀疏啟動，推理成本遠低於體量給人的想像） |
| 上下文視窗 | 100 萬 token（1,048,576），一口價不分檔 |
| 模態 | 原生支援文字 + 圖像理解（MoonViT-V2 視覺編碼器），部分管道已支援影片輸入 |
| 開源協議 | 自訂 Kimi K3 License（類 MIT，附收入分級條款） |

### 2.2 兩項核心技術創新

Kimi K3 的看點不只是「大」，更在於它處理資訊的方式：

**1. KDA 混合線性注意力（Kimi Delta Attention）**

傳統 Transformer 的全注意力機制處理長文字時，計算量隨文字長度接近平方級成長——內容增加 1 倍，計算量增至約 4 倍。這是超長文字難落地的根本原因。K3 在 93 層中的 69 層使用了自研的 KDA 線性注意力模組，把計算量壓到接近**線性成長**。結果是：KV 快取減少約 75%，百萬 token 解碼吞吐提升約 6.3 倍。簡單說，同樣算力下它能「讀」得更長、想得更深。

**2. 注意力殘差（Attention Residuals / AttnRes）**

模型越大、層數越多，資訊在層間傳遞越容易衰減失真，訓練越容易崩。注意力殘差技術讓模型跨深度有選擇地檢索表示，而不是機械地逐層累加——相當於給 2.8 兆參數的巨型模型裝了一套「穩定器」。官方稱，兩項技術疊加讓 K3 相比 K2 實現了約 **2.5 倍的訓練擴展效率**提升。

### 2.3 開源策略：人人可下載，但大廠要「報備」

7 月 27 日，K3 完整權重和技術報告登陸 Hugging Face 與 GitHub。許可證整體接近 MIT：任何人都可以免費使用、修改、分發、微調。只有兩條收入相關限制：

- 以「模型即服務」方式大規模轉售 K3 推理的雲廠商，連續 12 個月收入超 20 萬美元後需與 Moonshot 單獨簽約；
- 月活超 1 億或月收入超 200 萬美元的商業產品，需在介面顯著標註「Kimi K3」。

對絕大多數開發者和中小企業來說，這就是「免費可商用」。

## 四、在哪裡可以用上 Kimi K3？

這是大家最關心的部分，也是我最近一直在找的，記錄在這裡分享給大家，按門檻從低到高排列：

### 4.1 WorkBuddy（最省心的方式之一）

[https://www.workbuddy.cn/](https://www.workbuddy.cn/events/invite?inviteCode=421qev5h73caj0) （WorkBuddy 邀請連結）

為什麼不是首推 Kimi 官網呢？因為現在壓根就不開放，不知道什麼時候開放訂閱，等了有 2 週了我。除非你是 Kimi 的老會員，可以直接跳過哈哈。

**WorkBuddy 已經內建接入 Kimi K3**——你現在正在閱讀的這段對話，背後跑的就是 Kimi K3。對於不想折騰 API key、不想研究參數的普通使用者和辦公場景，打開 WorkBuddy 直接用即可：寫文件、做表格、讀 PDF、跑程式碼、生成網頁，K3 的長上下文和 Agent 能力在 WorkBuddy 裡是開箱即用的狀態。這也是國內使用者零門檻體驗 K3 完整能力的最短路徑之一。

### 4.2 Kimi 官方產品矩陣

https://kimi.com

- **Kimi 網頁版 / App**（kimi.com / kimi.moonshot.cn）：註冊即可對話，免費額度有上下文和頻率限制，會員解鎖完整 1M 上下文；
- **Kimi Work**：桌面端知識工作環境（Windows / Apple 晶片 Mac，3.1.0 版本起）；
- **Kimi Code**：終端程式設計 Agent，`npm i @moonshot-ai/kimi-code` 安裝，用 `/model` 切換到 K3。

### 4.3 官方 API（開發者）

- 平台：platform.moonshot.cn（國內）/ platform.kimi.ai（國際）；
- 完全相容 OpenAI SDK，模型 ID 為 `kimi-k3`，把 `base_url` 指向 `https://api.moonshot.ai/v1` 即可遷移現有程式碼。

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的 API Key",
    base_url="https://api.moonshot.ai/v1"
)
resp = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "幫我分析這段程式碼"}]
)
```

### 4.4 第三方平台

- **OpenRouter**：模型 ID `moonshotai/kimi-k3`，官方同價無加價；
- **矽基流動 SiliconFlow**：國內存取友好；
- **Cloudflare Workers AI、Groq**：也已上架；
- **自部署**：Hugging Face / GitHub 下載權重，支援 vLLM / SGLang，MXFP4/NVFP4 量化——但生產級部署需要 64 卡以上的超節點，普通人看看就好。

### 4.5 一個小提醒

K3 發布後因需求火爆，Kimi 官方會員一度暫停新購（7 月 20 日起優先保障存量使用者）。如果遇到官方管道擁擠，WorkBuddy、OpenRouter、矽基流動等都是可靠的替代入口。

## 五、寫在最後

Kimi K3 的意義，可能要到幾年後才能完全看清：

1. **它證明了開源可以追平閉源。** 2.8 兆參數、Arena 程式設計榜第一、智慧指數開源第一——「開源 = 二流」的時代結束了；
2. **它證明了中國團隊能做底層架構創新。** KDA 線性注意力和注意力殘差不是工程堆料，而是針對「超長文字算得省、超大模型訓得穩」這兩個世界級難題給出的原創解法；
3. **它把前沿能力的價格打了下來。** 三分之一的 Claude 價格、人人可下載的權重，會讓更多產品和研究站在 K3 的肩膀上長出來。

當然也要清醒：綜合體驗上它仍落後於最強的兩三個閉源模型，推理速度不快，思考模式燒 token 也狠。它不是萬能鑰匙，但如果你面對的是**長文件、整倉程式碼、深度調研、前端開發**這類硬骨頭任務，Kimi K3 就是目前開源世界能給你的最強答案——而且現在打開 WorkBuddy 就能用上。
