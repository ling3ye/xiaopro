DHT11 + GC9A01 圆屏打造 Game Boy 像素复古风温湿度计

用 ESP32-S3 驱动 GC9A01 240×240 圆屏配合 DHT11 传感器，复刻 Game Boy DMG 经典奶油绿四阶配色，做一个会闪烁告警的像素复古桌面温湿度计。附完整接线表、Arduino 库安装和全注释代码，新手友好。

  2. 安装两个库：Arduino IDE 搜索安装 Arduino_GFX_Library（Moon On Our Nation）和 DHT sensor library（Adafruit）

  5. 上电验证：圆屏亮起奶油绿底色，上半区温度（°C），下半区湿度（%），极端值自动闪烁告警

前言：一块会「玩」的温湿度计

说实话，我用过不少显示温湿度的方案——大 OLED 屏、小数码管、甚至串口打印……每次看到屏幕上孤零零的几个数字，心里都有种说不出的空虚感。又不是不能用，就是少了那么点灵魂。

直到有一天翻出了小时候的 Game Boy，那块经典的奶油黄绿屏突然给了我灵感：同样是显示数字，为什么不整得复古一点、好玩一点？

于是就有了这个项目——用 ESP32-S3 驱动一块 GC9A01 圆形 LCD，配上 DHT11 温湿度传感器，全程手写像素字体，把 Game Boy DMG 那套标志性的四阶绿色调搬到圆屏上，做一个摆在桌上就让人忍不住多看两眼的像素复古温湿度计。

没有现成 UI 库，没有复杂框架，全靠 fillRect() 一个格一个格地「堆」出像素数字——这种笨方法反而最有感觉。

实验效果

最终效果一句话描述：数值变化有缓动过渡，超限自动闪烁报警，帧率约 30fps，无任何撕裂闪烁。

元件说明

在买零件之前，先认识一下今天的三位主角。

ESP32-S3 · 这个项目里唯一有脑子的部分

ESP32-S3 是乐鑫出的 Wi-Fi + 蓝牙双模芯片，但今天我们用的不是它的网络能力，而是它充裕的 GPIO、充足的内存和足够快的 SPI 总线。

类比理解：如果 GC9A01 圆屏是一台电视机，ESP32-S3 就是那个往电视里塞节目信号的机顶盒。

  • 主频 240 MHz（双核 Xtensa LX7）
  • 内存 512 KB SRAM
  • 支持硬件 SPI，最高 80 MHz
  • 3.3V 工作电压

GC9A01 圆屏 · 像素复古感的来源

GC9A01 是分辨率 240×240 的圆形 IPS LCD 驱动芯片，接口标准 4 线 SPI。

  • 分辨率：240 × 240 像素
  • 接口：4 线 SPI
  • 色深：16 位 RGB565
  • 工作电压：3.3V

DHT11 · 多管闲事的小邻居

DHT11 是集温度 + 湿度于一体的低成本数字传感器，一根数据线就能回传两个数据。

  • 温度：0 ~ 50°C，±2°C
  • 湿度：20% ~ 90% RH，±5% RH
  • 接口：单总线
  • 工作电压：3.3V 或 5V

重点确认 VCC 接的是 3.3V 而不是 5V（GC9A01 接 5V 基本报废），DHT11 DAT 确认接 GPIO47。

安装所需库

Arduino IDE → 工具 → 管理库，搜索安装：

  1. Arduino_GFX_Library — 作者 Moon On Our Nation
  2. DHT sensor library — 作者 Adafruit，选 Install all

完整代码

代码结构：初始化 → 每 2 秒读传感器 → 每 33ms 双缓冲渲染 → 手写像素字体 + 闪烁告警。

C++gameboy_thermohygrometer.ino
/**
 * ESP32-S3 圆形温湿度计 · GAME BOY 像素怀旧版
 * 硬件：ESP32-S3 + GC9A01(240×240) + DHT11
 * 库  ：Arduino_GFX_Library + DHT(Adafruit)
 */

#include <Arduino_GFX_Library.h>
#include <DHT.h>

#define DHTPIN    47     // DHT11 数据引脚
#define DHTTYPE   DHT11
#define TFT_SCK   12     // GC9A01 SPI 时钟
#define TFT_MOSI  11
#define TFT_CS    9
#define TFT_DC    10
#define TFT_RST   18
#define TFT_BL    7

// DMG 四阶绿调色板（RGB565）
#define PAL_BG       0xCF69   // 奶油黄绿
#define PAL_DARK     0x3306   // 中绿
#define PAL_DARKEST  0x11C2   // 墨绿

#define CX  120  // 圆心 X
#define CY  120  // 圆心 Y
#define BOLD_SCALE  6

DHT dht(DHTPIN, DHTTYPE);
Arduino_DataBus *bus = new Arduino_ESP32SPI(TFT_DC, TFT_CS, TFT_SCK, TFT_MOSI, GFX_NOT_DEFINED);
Arduino_GFX *display = new Arduino_GC9A01(bus, TFT_RST, 0, true);
Arduino_GFX *gfx = new Arduino_Canvas(240, 240, display);

float g_temp = 0, g_hum = 0;
float g_dispTemp = 0, g_dispHum = 0;
bool  g_hasData = false;

void setup() {
  Serial.begin(115200);
  pinMode(TFT_BL, OUTPUT);
  digitalWrite(TFT_BL, HIGH);
  gfx->begin();
  gfx->fillScreen(PAL_BG);
  gfx->flush();
  dht.begin();
  delay(2000);
  float t = dht.readTemperature();
  float h = dht.readHumidity();
  if (!isnan(t) && !isnan(h)) {
    g_temp = g_dispTemp = t;
    g_hum  = g_dispHum  = h;
    g_hasData = true;
  }
}

unsigned long lastRead = 0, lastFrame = 0;

void loop() {
  unsigned long now = millis();
  if (now - lastRead >= 2000) {
    lastRead = now;
    float t = dht.readTemperature();
    float h = dht.readHumidity();
    if (!isnan(t) && !isnan(h)) { g_temp = t; g_hum = h; g_hasData = true; }
  }
  g_dispTemp += (g_temp - g_dispTemp) * 0.08f;
  g_dispHum  += (g_hum  - g_dispHum)  * 0.08f;
  if (now - lastFrame >= 33) {
    lastFrame = now;
    gfx->fillScreen(PAL_BG);
    char num[8];
    if (g_hasData) snprintf(num, sizeof(num), "%.1f", g_dispTemp);
    else strcpy(num, "--.-");
    drawValue(num, "*C", 62, tempColor(now));
    if (g_hasData) snprintf(num, sizeof(num), "%.1f", g_dispHum);
    else strcpy(num, "--.-");
    drawValue(num, "%", 142, humColor(now));
    gfx->flush();
  }
}

uint16_t tempColor(unsigned long t) {
  if (!g_hasData) return PAL_DARK;
  return (g_dispTemp > 35.0f || g_dispTemp < 5.0f) && (t / 400) % 2 == 0 ? PAL_BG : PAL_DARKEST;
}

常见问题排查

屏幕通电后完全不亮

BL 引脚检查 GPIO7 接线，或把 BL 直接接 3.3V 绕过代码控制。

背光亮但屏幕全黑/雪花

SPI 接线重点查 SCK/MOSI/CS/DC，DC 和 CS 极易接反。

[WARN] DHT11 读取失败

  • DAT 接 GPIO47
  • 散装版需 10kΩ 上拉电阻
  • delay(2000) 不能删
  • 确认 VCC 3.3V

FAQ

QGPIO 可以换成其他编号吗？

可以，改顶部 #define 即可。SCK/MOSI 建议用硬件 SPI 默认引脚（11/12）。

QDHT11 能换 DHT22 吗？

可以，#define DHTTYPE DHT22，其余不变。DHT22 精度更高，采样间隔 2 秒兼容。

QESP32-S3 的 GPIO 能接 5V 吗？

不能，GPIO 耐压 3.3V。5V 传感器需加分压电阻或电平转换模块。

Q数值一直 --.- 不刷新？

① 确认 DAT 接 GPIO47；② 散装版需上拉电阻；③ 串口监视器查看输出；④ 确认 VCC 电压。
