💻 核心代码

pixel-thermometer.ino Arduino 
#include <Adafruit_GC9A01A.h>
#include <DHT.h>

#define DHTPIN 4
#define DHTTYPE DHT11
#define TFT_CS 10
#define TFT_DC 13
#define TFT_RST 14

Adafruit_GC9A01A tft(TFT_CS, TFT_DC, TFT_RST);
DHT dht(DHTPIN, DHTTYPE);

// Game Boy DMG 四阶绿色调色板
const uint16_t DMG_COLORS[4] = {
  0x18E3, 0x3146, 0x8C51, 0x9CD3
};

void setup() {
  Serial.begin(115200);
  tft.begin();
  tft.fillScreen(DMG_COLORS[0]);
  dht.begin();
}

void loop() {
  float h = dht.readHumidity();
  float t = dht.readTemperature();
  if (isnan(h) || isnan(t)) { delay(2000); return; }
  drawPixelFrame();
  drawTemp(t);
  drawHumidity(h);
  delay(2000);
}

🎯 运行效果

  • 屏幕顶部显示 Game Boy 风格标题栏 "GB-THERMO"
  • 中间大字显示温度（℃）和湿度（%）
  • 底部像素进度条展示湿度百分比
  • 每 2 秒刷新，刷新时有像素翻页动画

🚀 扩展建议

  • 替换 DHT11 为 DHT22（精度 ±0.5℃）
  • 加入 WiFi + MQTT 上报至 Home Assistant
  • 添加锂电池供电，做成便携设备
  • 加入 microSD 离线数据记录
